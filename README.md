# AI-103 Quiz Lab

Static, dependency-free quiz application generated from the bundled `AI-103.pdf` (157 questions). Open `index.html` directly or deploy the folder to Vercel; no backend is required.

`data/questions.js` is generated by `scripts/import_pdf.py`. Image/table items are preserved with `needsReview: true`, never guessed. Run `node scripts/validate.js` to validate numbering, IDs, answers, explanations, cues, option references, selection sizes, random uniqueness, scoring prerequisites, and persistence configuration.
